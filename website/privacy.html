Privacy Policy

Last updated: June 1, 2026

Local-only by design

Tacket saves AI chat conversations only when you explicitly choose to save, capture, or add one to the library. Browser conversations are sent from the extension to the Tacket app on your Mac. Desktop app conversations are captured locally by the Mac app using macOS Accessibility and on-device OCR when needed, then shown in a local preview before saving. Saved chats are written to local files and added to local search only when you choose to index them.

What Tacket does not collect

  • No analytics
  • No telemetry
  • No remote crash reports
  • No background chat collection
  • No model/API calls
  • No Tacket backend account

Browser permissions

The Chrome extension requests access only to supported AI chat sites and only uses that access after you click the save button. It refuses to save pages outside ChatGPT, Claude, and Gemini.

Installing through the Chrome Web Store means Google handles extension distribution. Tacket does not send saved chat text to me or to a Tacket server; the saved conversation goes from the extension to the Tacket app on your Mac.

macOS permissions

Native desktop app capture may ask for Accessibility or Screen Recording permission. Tacket uses those permissions to scroll and read the open ChatGPT, Claude, or Codex desktop app chat locally, then asks you to review the captured text before saving. It does not use those permissions for background monitoring, analytics, or uploading chat text.

If you enable the optional menu bar Quick Capture item, it uses the same desktop capture preview flow. It does not continuously watch the frontmost app and does not save chats without your click.

Planned local imports

Direct imports from Codex App, Claude App, and Claude Code are planned, but they are not part of the current working release. Future import work will follow the same local-only rule: no Tacket backend, no analytics, and no model calls.

Local files

Saved chat folders may contain private conversation text, code, images, and attachment references. You control where those files are stored and whether they are shared with other tools.

Local search

Tacket's library search runs on your Mac. It does not create embeddings, call a model, sync to a server, or send searchable chat text to me.

Contact

Open an issue on the Tacket GitHub repository for general privacy questions. For security vulnerabilities, use GitHub private vulnerability reporting when available, or open a minimal public issue asking for a maintainer security contact without including private details.
