Built for handoff, not summaries

Sometimes the useful context is already in a chat. Tacket moves that thread as-is, so you do not have to ask another model to summarize it and hope the important parts survive.

Local by default

Captures are plain local files on your Mac. There is no Tacket backend, no hosted database, no telemetry, and no model/API calls.
