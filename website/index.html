Local-first thread transfer

Move complete AI chat threads into coding agents.

Tacket captures raw ChatGPT, Claude, and Gemini conversations in Chrome, stores them as inspectable local bundles, and transfers the full transcript into Codex or Claude Code without summarizing it.

Download for Mac View source

User-click capture

The extension reads a supported chat page only after you click Capture This Thread.

Raw transcript transfer

Tacket preserves the full thread as files and clipboard text instead of generating a summary.

No backend

Bundles are written to your Mac. There is no cloud account, telemetry, or hosted database.
